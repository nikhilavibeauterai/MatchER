# Source for MatchER desktop releases

MatchER is licensed under GNU GPL version 3 only. The complete license is included in `LICENSE`
(desktop resources: `MATCHER-LICENSE.txt`). There is no warranty; see the license for details.

Source repository: **https://github.com/nikhilavibeauterai/MatchER**

For the exact version shown in **Help → About**, open the matching `v<version>` tag, or use the
**Source code (zip / tar.gz)** links on that release. These archives include the application source,
desktop wrapper, pinned dependency manifests and build scripts. For example, version 0.1.0 corresponds to
https://github.com/nikhilavibeauterai/MatchER/tree/v0.1.0.

Build instructions are in `docs/building.md`. Third-party components retain their respective licenses;
their notices and version inventory are included in the backend's `_internal/licenses/` directory and
Electron's `LICENSES.chromium.html`. See `THIRD_PARTY_NOTICES.md` for upstream source and model links.

If you distribute a modified build, provide its matching source and build instructions under GPL-3.0,
preserve the third-party notices, and update this file to point to that source.
